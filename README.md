# Kavindu Prabhath — Project Management Portfolio

## Run locally
1. Extract this ZIP.
2. Open the folder in Visual Studio Code.
3. Open Terminal → New Terminal.
4. Run `python -m http.server 8000` (or `py -m http.server 8000` on Windows).
5. Visit http://localhost:8000.

You can also double-click `index.html`, but a local server is recommended.

## Add your photograph
The original photograph could not be reattached in this replacement archive. Put your professional photo inside the `assets` folder and name it `profile.jpeg`. The homepage will show a placeholder until you add it.

## Edit content
- Homepage: `index.html`

## Publish with GitHub Pages
1. Create a public repository named `prabathkavindu0-byte.github.io` in your GitHub account.
2. In this folder, open a terminal and run:

   ```bash
   git init
   git add .
   git commit -m "Create project management portfolio"
   git branch -M main
   git remote add origin https://github.com/prabathkavindu0-byte/prabathkavindu0-byte.github.io.git
   git push -u origin main
   ```

3. In GitHub, open repository Settings → Pages.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. After deployment, visit https://prabathkavindu0-byte.github.io/.

## Before publishing
